# 내 방 부수기

- **제작**: 주현진
- **한 줄 소개**: 망치로 벽과 가구를 부수고, 스프레이·도장·화염방사기로 마음껏 어지르는 VR 스트레스 해소 게임
- **플랫폼**: Meta Quest 3S (Android APK), Unity 6000.3.15f1, URP
- **씬**: `Assets/Scenes/BreakMyRoom.unity`
 - **시연 영상**: https://youtu.be/i_lOCzWWD9o

## 사용한 XR 기능

- **XRI 잡기**: 다섯 도구를 Grip으로 잡기(XRGrabInteractable), 레이로 먼 도구도 손으로 당겨 잡기
- **XRI 레이 UI**: 컨트롤러 레이 + Trigger로 시작·종료·다시 하기 등 버튼 누르기
- **XRI 호버**: 잡을 수 있는 도구에 흰 외곽선 표시
- **머리·손 추적**: 손 속도로 망치 휘두르기 판정, 머리를 따라오는 도구 HUD와 타이틀·결과 화면
- **햅틱**: 망치 타격·도장 찍기 진동
- **OpenXR + Unity OpenXR: Meta**, Floor 추적

## 주요 기능

- **부서지는 방**: 네 벽·바닥·천장 150칸과 가구 9개. 칸은 균열 → 조각 3개 → 완전 파괴, 가구는 금 → 조각 4개씩 파괴
- **망치**: 휘두른 방향 50cm 안의 가장 가까운 대상 하나 파괴, 타격음과 진동
- **스프레이**: 분홍 분사 입자와 자국, 칸 경계를 넘어 이어지는 선
- **도장**: Trigger 1회에 웃는 얼굴 자국 1개, 구석·모서리에서 면을 따라 꺾임
- **화염방사기**: 불꽃 입자와 겹칠수록 진해지는 그을음
- **물총**: 조준점 주변의 자국 세척
- **자국**: 최근 자국이 항상 위, 물총 전까지 유지, 부서진 조각에 붙어 함께 떨어짐
- **게임 흐름**: 타이틀(앱 이름·제작자) → 플레이(시간 제한 없음) → 결과 화면(플레이 시간, 부순 칸·가구 수, 남은 자국 수) → 다시 하기 / 처음 화면

## 조작

| 동작 | 방법 |
| --- | --- |
| 도구 잡기 | 고개를 내려 HUD의 도구에 손을 대거나 레이로 가리키고 Grip |
| 도구 놓기 | Grip을 놓으면 0.35초 뒤 HUD로 복귀 |
| 사용 | 도구를 든 손의 Trigger (망치는 휘두르기) |
| 버튼 | 레이로 가리키고 Trigger |
| 이동 | 없음 (제자리, 멀미 방지) |

앞 벽 버튼: `도구 정리`, `방 복구`, `자국 지우기`, 그 아래 `종료 · 결과 보기`

## 느낀점

평면 게임에서는 당연했던 "때리면 부서진다"를 VR에서 자연스럽게 느끼게 만드는 것이 생각보다 어려웠습니다. 처음에는 망치가 벽에 정확히 닿아야만 부서져서 답답했는데, 휘두른 방향의 가장 가까운 대상을 부수도록 바꾸고 나서야 손맛이 살아났습니다. 에디터에서는 괜찮아 보여도 헤드셋을 쓰면 도구 거리, 스프레이가 얼마나 잘 보이는지, 바닥 높이가 전혀 다르게 느껴져서, 기기에서 직접 확인하는 과정이 가장 중요하다는 걸 배웠습니다. 기능을 늘리기보다 "부수는 경험" 하나를 다듬는 데 집중한 것이 좋은 선택이었다고 생각합니다.

- **손맛·조작**: 망치 판정에 여유를 두고 휘두른 방향으로 판단하게 하니 손맛이 살아났고, 도구도 손에 딱 붙이기보다 15cm쯤 띄워야 자연스러웠습니다.
- **VR에서의 보임**: 화면에서 보이던 스프레이가 헤드셋에서는 잘 안 보여 입자를 훨씬 진하게 만들었고, 글이 많으면 읽기 부담스러워 제목·이름·버튼만 남겼습니다. 타이틀은 한 자리에 고정하기보다 시선을 따라오는 편이 편했습니다.
- **실기기 테스트**: macOS에서는 실제 기기로 Play 모드를 실행할 수 없어 빌드·설치를 여러 번 반복했습니다. 바닥이 허리 높이로 보였던 원인이 코드가 아니라 주변 가구 때문에 Quest가 바닥을 잘못 잡은 것이어서, 하드웨어와 공간 환경도 개발의 일부라고 느꼈습니다.
- **설계**: 멀미를 피하려고 이동 없이 제자리에서 모두 부술 수 있는 크기로 방을 만들었고, 점수나 시간 제한 없이 마음껏 부수는 해방감에 집중했습니다.
- **아쉬운 점**: 실제 기기에서 성능(FPS)을 충분히 측정하지 못했습니다. 다음에는 손 추적이나 패스스루(MR)로 내 실제 방을 부수는 버전도 만들어 보고 싶습니다.

## 빌드와 확인

1. Android 플랫폼, `BreakMyRoom`만 체크한 상태로 APK 빌드 → `adb install -r <apk>`
2. Quest에서 바닥 높이·플레이 영역 설정 후, 영역 중앙에서 앞을 보고 실행
3. 확인 항목: 레이 버튼 클릭, 도구 잡기·복귀, 망치 판정 거리(50cm), 자국·세척, 결과 화면, 다시 하기
4. 성능: 여러 칸·가구를 부수고 자국을 채운 상태에서 OVR Metrics Tool로 FPS 확인

에디터 Play Mode 자동 검사와 렌더링 확인을 거쳤고, Quest 3S에서는 설치·실행·OpenXR 초기화까지 확인했습니다. 실제 손맛·진동·성능은 기기에서 확인이 필요합니다.
